# Prompt tạo toàn bộ âm thanh (ElevenLabs Sound Effects + Suno), 12/11/2026

Đi kèm danh sách `24-am-thanh.md`.

**Cách làm**
1. Dán prompt vào ElevenLabs → Settings: Duration = cột "Dài", Prompt influence ~70%.
2. Generate. Mỗi lần ra vài bản, chọn bản có đầu tiếng rõ và đuôi tắt nhanh.
3. Tải mp3, đổi tên đúng cột "Tên file" rồi gửi dạng **File**.
4. Cột "Bản" là số biến thể nên có: Generate thêm lần nữa với cùng prompt, đặt `_1`, `_2`, `_3`.

**Phong cách chung:** giống tiếng kiếm đã duyệt: thật, chắc, gọn, không vang dài, không chói.

Các prompt đã có sẵn đuôi `game sound effect, no music` (riêng tiếng có giọng thì bỏ `no voice`). Nếu bản nào ra có nhạc nền, thêm `no music, no background` rồi tạo lại.
